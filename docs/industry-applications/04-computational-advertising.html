Computational Advertising (O2O)

End-to-End O2O Advertising System

This project demonstrates a complete computational advertising workflow for Online-to-Offline (O2O) platforms, following the structure outlined in Meituan’s Machine Learning Practice, Chapter 11-12: Computational Advertising — including business constraints, auction & ranking design, user preference modeling, and loss construction.

1. Problem Definition

We aim to build an O2O advertising system that balances three objectives: merchant ROI, user experience, and platform revenue. Unlike traditional recommendation systems, O2O ads must handle geographic constraints, real-time inventory, and offline conversion tracking.

Task Type

  • Multi-objective optimization: Balance revenue, relevance, and satisfaction
  • Ranking: Prioritize ads per user query and context
  • Pairwise learning: Model relative user preferences

Business Constraints

  • Geographic relevance: Ads must be within delivery radius
  • Time sensitivity: Lunch/dinner hour targeting
  • Budget pacing: Merchant daily spend limits
  • User fatigue: Limit ad exposure to maintain platform health

6. Ad Ranking System

6.1 Score Computation

def compute_ad_score(row, ctr_pred, cvr_pred):
    """
    Production ad ranking score:
    Score = Bid × P(click) × P(conversion|click) × Quality
    """
    bid = row['bid_price']
    ctr = ctr_pred
    cvr = cvr_pred

    # Quality score components
    quality_factors = {
        'rating': row['merchant_rating'] / 5.0,
        'distance': max(0, 1 - row['distance_km'] / 5),  # Penalize distance
        'delivery': max(0, 1 - row['avg_delivery_time'] / 60)  # Penalize slow delivery
    }

    quality = np.mean(list(quality_factors.values()))

    score = bid * ctr * cvr * quality

    return score

# Compute scores for test set
test_df['ctr_pred'] = ctr_model.predict_proba(test_df[ctr_features].fillna(0))[:, 1]

6.2 Ranking Evaluation

def ndcg_at_k(y_true, y_scores, k=10):
    """Compute NDCG@K for ranking evaluation"""
    idx = np.argsort(y_scores)[::-1][:k]
    dcg = np.sum([(2 ** y_true[i] - 1) / np.log2(i + 2) for i in idx])
    ideal_idx = np.argsort(y_true)[::-1][:k]
    ideal_dcg = np.sum([(2 ** y_true[i] - 1) / np.log2(i + 2) for i in ideal_idx])
    return dcg / ideal_dcg if ideal_dcg > 0 else 0

# Evaluate ranking quality

7.1 Pairwise Preference Learning

from sklearn.utils import shuffle

def create_pairwise_data(df, n_pairs=10000):
    """
    Create pairwise training data for preference learning
    For each user: sample pairs (ad_i, ad_j) where label=1 if ad_i preferred over ad_j
    """
    pairs = []

    for user_id in df['user_id'].unique()[:100]:  # Sample 100 users for demo
        user_data = df[df['user_id'] == user_id]

        if len(user_data) < 2:
            continue

        # Positive samples (clicked)
        clicked = user_data[user_data['clicked'] == 1]
        not_clicked = user_data[user_data['clicked'] == 0]

        # Sample pairs: clicked vs not_clicked
        for _ in range(min(5, len(clicked), len(not_clicked))):
            if len(clicked) > 0 and len(not_clicked) > 0:
                pos_sample = clicked.sample(1).iloc[0]
                neg_sample = not_clicked.sample(1).iloc[0]

                # Create positive pair: clicked item preferred
                feature_diff = {
                    'distance_diff': pos_sample['distance_km'] - neg_sample['distance_km'],
                    'rating_diff': pos_sample['merchant_rating'] - neg_sample['merchant_rating'],
                    'delivery_diff': pos_sample['avg_delivery_time'] - neg_sample['avg_delivery_time'],
                    'bid_diff': pos_sample['bid_price'] - neg_sample['bid_price']
                }
                feature_diff['label'] = 1  # pos_sample preferred
                pairs.append(feature_diff)

                # Create negative pair: reverse the order
                feature_diff_neg = {
                    'distance_diff': neg_sample['distance_km'] - pos_sample['distance_km'],
                    'rating_diff': neg_sample['merchant_rating'] - pos_sample['merchant_rating'],
                    'delivery_diff': neg_sample['avg_delivery_time'] - pos_sample['avg_delivery_time'],
                    'bid_diff': neg_sample['bid_price'] - pos_sample['bid_price']
                }
                feature_diff_neg['label'] = 0  # neg_sample NOT preferred
                pairs.append(feature_diff_neg)

    return pd.DataFrame(pairs)
